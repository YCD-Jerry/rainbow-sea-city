# 虹海之城

浏览器里的《原神》式 3D 开放世界，Three.js 写成，构建成单个 HTML 文件。

**在线玩：https://ycd-jerry.github.io/rainbow-sea-city/**（每次推送到 `main` 约 1–2 分钟后自动更新）

```bash
npm ci
node build.mjs        # 生成 rainbow-sea-city.html、test.html、dist/index.html
```
