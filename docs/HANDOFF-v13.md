# 虹海之城 · 交接说明（v13，2026-10-03）

给接手的 AI（新的 Claude 对话 / ChatGPT / 其他）看的。请先完整读完再动手。

## 1. 这是什么

一个模仿《原神》体验的浏览器 3D 开放世界游戏：Three.js 写的，打包成**单个 HTML 文件**，发布在 claude.ai 上。

- 在线链接（每次更新都发布到这一个链接，不要新开）：https://claude.ai/artifact/LnY6RCzuR9mn143ZP4hraP
- 当前版本：v13（昼夜与时间跳转、七符封印大解谜、挑战重开、测试工具）

## 2. 用户定下的规矩（必须遵守）

- 交付方式：直接给在线链接在浏览器里打开，不要发需要下载的文件。
- 地图在任何时候都能打开，除非用户另外说明。
- 宝箱名称严格按原神：普通的宝箱 / 精致的宝箱 / 珍贵的宝箱 / 华丽的宝箱。
- 除宝箱外，所有名称、角色、剧情和美术都是原创的：功能上可以对标原神，但不抄它的 IP。
- 不做元素反应。核心机制是「光」：
  - 光源：弓手的光箭。
  - 光媒：潮帘 / 聚晶 / 蜃雾 / 海镜。
  - 光媒会和大世界互动，例如瀑布、晶石和海雾。
- 回复用中文，简洁，分点说明改了什么、测了什么。
- 用户经常一次提很多条要求：逐条做完，逐条回应。用户自己设计的谜题要严格按他的设计实现。

## 3. 源码、构建与发布

源码结构：

```
package.json      依赖：three@0.165.0、esbuild@0.28、playwright-core（仅测试用）
build.mjs         esbuild 把 src/main.js 打成 IIFE，塞进 template.html 的 <script>/*BUNDLE*/</script>
template.html     全部 HTML 与 CSS（各种界面、面板、HUD）
src/*.js          游戏代码（见第 4 节）
```

构建：

```
npm install
node build.mjs          # 压缩版 → rainbow-sea-city.html（发布用，约 1.1 MB）
DEV=1 node build.mjs    # 不压缩，便于调试
```

`build.mjs` 同时生成 `test.html`，即带完整 `<html>` 外壳的本地测试版。打开 `test.html?debug` 时会暴露 `window.__dbg` 调试接口。

发布（仅 Claude）：

- 用 Artifact 工具，`url` 填上面的链接，`file_path` 指向 `rainbow-sea-city.html`。
- 新会话要先对这个链接执行 `read`，然后才能发布更新。

> 发布的文件不带 `<!doctype>`、`<html>` 外壳：claude.ai 发布时会自动包一层。直接在本地浏览器里打开，要用 `test.html`。

### 没法 npm install 的环境（例如 ChatGPT）

交接压缩包里有两个能直接在浏览器打开的成品：

- `虹海之城-可读版.html`：未压缩、three.js 已内联。可以直接修改这个文件，改完在浏览器里打开就能玩。
- `虹海之城.html`：压缩版。

改完后，把新的 HTML 交给 Claude，由 Claude 读过后发布到同一个链接。这时 `src/` 里的源码就落后了，需要把改动同步回源码。

### 从项目文档「源码包」恢复源码

项目里的 `claude/source-pack.txt` 是全部源码拼成的一个文本文件。每个文件以一行 `===== FILE: 路径 =====` 开头。恢复方法：

```python
import re, os
txt = open('source-pack.txt', encoding='utf-8').read()
for path, body in re.findall(r'^===== FILE: (.+?) =====\n(.*?)(?=^===== FILE: |\Z)', txt, re.S | re.M):
    os.makedirs(os.path.dirname(path) or '.', exist_ok=True)
    open(path, 'w', encoding='utf-8').write(body.rstrip('\n') + '\n')
```

## 4. 代码地图（src/）

| 文件 | 内容 |

| terrain.js | 地形高度函数 H、海岸线 coastX、岛屿、地形平整垫 addPad / reserved |
| city.js | 海湾新城：大道、单轨环线与车站、悬浮车、无人机、路灯；夜间窗户与路灯光 nightMats / nightFx |
| structures.js | 风帆塔、桥、传送锚点 waypoint、虹之像 |
| nature.js / nearfade.js | 树、草、灌木；近处半透明淡出 |
| sky.js / water.js / daynight.js | 天空（星星、月亮）、海面（反射、昼夜）、昼夜系统（1 现实秒 = 1 游戏分钟） |
| player.js | 角色数据 CHARS、移动、攀爬、滑翔、游泳、攻击、瞄准 |
| combat.js / enemies.js / fx.js / media.js | 战斗、光箭与光媒、可打击物 breakables、敌人、特效 |
| items.js / artifacts.js / chests.js / loot.js | 道具与背包、遗珍、四种宝箱模型、掉落与封印 |
| gacha.js | 拾光（抽卡）：限定池「琥珀晶辉」、常驻池「海湾拾光」 |
| domain.js | 回廊（秘境）的入口与浮空竞技场 |
| puzzles.js | 8 个大世界谜题，位置在 `planPuzzles()` 里规划 |
| story.js / lore.js | 主线序章「彩虹下的来客」；集光塔、遗迹 |
| achievements.js | 成就（7 个分类） |
| map.js / ui.js / charmodel.js | 地图、背包与角色界面、二次元角色 3D 模型 |

主流程的顺序：

1. `planCity`、`planPuzzles`、`planStructures` 先登记平整垫；
2. `buildTerrain` 生成地形；
3. 摆放各种物件；
4. 进入主循环。

新增建筑或谜题时，平整垫要在 `buildTerrain` 之前加。

## 5. 测试方法

- 无头 Chromium（swiftshader）大约 1 fps，所以逻辑测试直接调用 `__dbg` 接口，不靠真实按键加时间推进：
  - `__dbg.tick(n, dt)` 推进谜题；
  - 循环调用 `player.update(dt, inp, cam.yaw)` 推进角色；
  - `__dbg.puzzles.list[i].debug` 是谜题内部状态。
- 画面检查：用 `__dbg.setCam({p, t, fov})` 固定机位截图，`__dbg.dayNight.time = 分钟数; __dbg.dayNight.apply()` 切换时间。
- 截图很慢（几秒），会让 3 秒提示框这类计时 UI 在截图期间消失：这是测试环境的问题，不是 bug。

## 7. 七符封印（用户亲自设计的大解谜，不要改动规则）

- **位置**：东方高地，坐标约 (400, 40)，附近有传送锚点「七符台」。
- **转盘**：
  - 圆环分 7 格，每格一种颜色、一个符文。
  - 从北方起顺时针的字母顺序是 G F A E B D C。整体略微旋转过，让一道缝隙正对西侧的操作台。
- **符文**：每个都是字母 A–G 与它的镜像拼成的对称图形。玩家事先不知道这是字母。

  | 字母 | 图形 |
  |---|---|
  | A | X，下半部有一道横杠 |
  | B | 中间带竖线的「8」 |
  | C | O |
  | D | 带竖直直径的 O |
  | E | 王 |
  | F | 上横、两竖、中横，底部开口 |
  | G | 内含「⊤」的 O |

- **颜色**：红橙黄绿青蓝紫在每个存档里随机分配给 7 个字母，存在 `save.puzzles.seal.colors`（`colors[字母序号] = 颜色序号`）。
- **密码**：按 A→G 的顺序读出颜色。
- **操作**：在西侧操作台按顺序按下 7 个晶钮（按 F 或攻击都可以）。晶钮从左到右是彩虹顺序。
- **反馈**：按满 7 个之前不提示对错。对了：封印破碎，出现华丽的宝箱，并解锁隐藏成就「镜中之字」。错了：清空重来；错满 5 次后会弹出一句轻微的提示。
- **石碑提示**：「七色各守一符。每一枚符都只写了一半，另一半是它在镜中的倒影。循符之序，依次按下七色，大封自解。」
